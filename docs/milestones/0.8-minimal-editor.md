# 0.8 Minimal editor

**Stage:** 0 · **Duration:** 1 d · **Depends on:** 0.2 · **Needed for:** 1.1, 6.1

## Goal
Confirm that a VPN editor for plasma-nm builds outside the plasma-nm tree against headers copied from tag 6.7.4, is loaded by the stock plasma-nm from forky and saves a profile. The whole approach to the UI and packaging depends on this.

## Inputs
- The VM from 0.2 with `plasma-nm` and the Qt 6/KF6 dev packages.
- [design.md](../design.md), section “plasma-nm user interface”: items “Build”, “Translations”, “Discovery”, “Who loads the plugin”; plasma-nm's built-in import and export are not supported.
- [design.md](../design.md), section “Architecture”, item “Service names follow the protocol, not the core”.
- [design.md](../design.md), section “Packages”, item “plasma-nm compatibility”: the `qt6/plugins/plasma/network/vpn/` directory, the Qt version constraint.
- plasma-nm sources, tag v6.7.4: `libs/editor/vpnuiplugin.h`, `libs/editor/widgets/settingwidget.h`, `libs/editor/widgets/passwordfield.h`; reference module: `vpn/sstp/` (`CMakeLists.txt`, `sstp.cpp`, `plasmanetworkmanagement_sstpui.json`).

- [x] Check the module's dependencies: `ldd` and `nm -D --undefined-only` — external plasma-nm symbols are resolved only from `libplasmanm_editor.so`.
- [x] Update design.md: in “plasma-nm user interface”, item “Build”, confirm or correct the list of libraries and headers; record what the check without `pnv-proto.name` showed: whether the “Add VPN” list is built from plugin metadata only (`libs/models/creatableconnectionsmodel.cpp`) and whether saving works without `.name`.

## Risks and notes
- ABI compatibility of the 6.0.0–6.8.3 headers has already been established in design.md; no need to recheck it. It is important to build against the same Qt minor version as in forky: Qt rejects a plugin built against a newer one.
- kded6 and systemsettings keep a loaded plugin in memory until they are restarted (the applet in plasmashell reads only the metadata, design.md, item “plasma-nm compatibility”); after a rebuild, restart System Settings, and for the password prompt, kded6 or the session.
- If the VM has a plasma-nm other than 6.7.x, that is acceptable (the 6.x ABI is stable), but record the version.
- Secrets, `PasswordField` and import are not done here: that is 6.1–6.7.
- Results: `proto/0.8/NOTES.md` and design.md, “plasma-nm user interface”, items “Build” and “Discovery”.
